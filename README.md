# Austral Patagonia Naviera 🚤🏔️

Sitio web oficial y plataforma de tours y navegación de **Austral Patagonia Naviera** (Puerto Montt, Región de Los Lagos, Chile). Especialistas en excursiones por los fiordos patagónicos, lagos glaciares y volcanes.

## 🌟 Características

- **Diseño Moderno y Responsivo**: Navegación fluida y componentes visuales adaptados a móvil y escritorio.
- **Catálogo de Excursiones**: Lago Todos los Santos, Cruce Andino, Volcán Osorno y Petrohué, Chiloé (Castro / Dalcahue), Termas del Sol & Cochamó, Transfers Aeropuerto El Tepual.
- **Sistema de Reservas**: Modal interactivo de solicitud de reserva con confirmación inmediata.
- **Multidioma**: Soporte completo para Español (ES) e Inglés (EN).
- **Newsletter de Aventuras**: Suscripción rápida para promociones y novedades turísticas.

## 🚀 Tecnologías

- **React 19**
- **Vite**
- **Swiper** (Sliders interactivos)
- **CSS3 / Modern Responsive Design**

## 🛠️ Instalación y Uso Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/nowebcl/patagoniaaustral.git
   cd patagoniaaustral
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
